## 一、 架构演进背景与性能瓶颈研判

平台在 V2.0 阶段采用轻量级单体架构（PostgreSQL + 本地文件存储 + 本地内存缓存），在百人级在册规模与低并发操作下表现出色。然而，随着平台向全集团全员推广、并作为全州国企数字化党建标杆进行辐射推广时，面临以下系统级瓶颈：

| 维度 | 轻量级单体现状 (V2.0) | 万级党员/多组织并发瓶颈 | 企业级升级解法 (V3.0) |
| :--- | :--- | :--- | :--- |
| **文件与附件存储** | 本地磁盘文件夹存储 (`./uploads`) | 磁盘空间受限；大附件上传阻塞应用线程；无法多节点水平扩展与直传 | **MinIO 分布式对象存储** (S3兼容，支持分片、冷热分级与预签名直传) |
| **缓存与状态协同** | Spring 本地内存 Map 缓存 | 无法多实例共享；大屏聚合频繁慢查扫库；并发操作缺乏分布式锁 | **Redis 7.x 集群/哨兵** (分布式缓存、分布式防重锁、Token共享中枢) |
| **全库检索与分析** | PostgreSQL `ILIKE` 模糊查 | 跨表文本多维度检索无法利用常规索引；无中文分词；海量台账检索慢 | **Elasticsearch 8.x + IK 分词器** (全息党务搜索引擎，毫秒级聚合并发) |
| **红头材料协同** | 依赖本地 Office 下载与上传 | 体验割裂；排版与版本失控；领导审批无法在线划线批注与预览 | **ONLYOFFICE Document Server** (网页端原生高保真即时在线预览与协同) |

## 三、 四大核心中间件技术选型与职责边界

### 1. 分布式缓存中枢：Redis 7.x
- **职责定位**：
  1. **JWT 令牌与多端会话共享**：支持黑名单快速作废、多端单点登录（SSO）与踢出控制；
  2. **多渠道开放平台凭证缓存**：企业微信 `access_token`、钉钉应用令牌集中缓存与全局续期，避免频繁调用服务商触发频率拦截；
  3. **大屏核心 KPI 与合规状态秒级缓存**：指挥大屏每秒轮询直接命中 Redis，屏蔽对 PostgreSQL 的高频重型统计 SQL；
  4. **Redisson 分布式防重锁**：在发展党员关键步骤推进（如第20步总支审批）、党费缴纳、批量导入时加分布式锁，防网络抖动并发重复提交。

### 2. 分布式对象存储：MinIO
- **职责定位**：
  1. **S3 协议兼容体系**：支持多租户、分桶（Bucket）管理：
     - `party-materials`：发展党员 25 步过程材料（志愿书、思想汇报、谈话表等）；
     - `party-meetings`：三会一课会议纪要、票决书、签到表、现场高清纪实照片；
     - `party-templates`：25 步官方内置与企业红头定制 DOCX 模板；
  2. **客户端直传与预签名（Presigned URL）**：大文件、大图直接通过预签名 URL 直传 MinIO，彻底释放 Spring Boot 业务服务器带宽与内存；
  3. **数据加密与访问控制**：私有桶配合受控临时签名下载，防止越权下载敏感党员档案。

### 3. 党务全文搜索引擎：Elasticsearch 8.x + IK 中文分词
- **职责定位**：
  1. **党务全息档案毫秒级检索**：对党员档案、三会一课研讨决议、主题党日纪实正文进行结构化索引与高亮全文检索；
  2. **中组部规程与党规党纪智能库**：支持党务干部按关键字（如“转正期限”、“一票否决”）快速穿透检索《细则》、《条例》与政策解释；
  3. **多维聚合分析**：为驾驶舱提供更深度的队伍年龄、学历、一线分布与双培养转化率实时下钻分析。

### 4. 在线文档预览与协同：ONLYOFFICE Document Server
- **职责定位**：
  1. **网页端原生高保真预览**：点击“一人一档”抽屉内任意 `.docx` 过程材料，直接在内嵌容器打开，100% 还原 Word 格式与排版，无需本地安装 Office；
  2. **红头文件套打在线核对**：系统占位符自动填报后，组织员可直接在浏览器中核查排版并进行微调保存；
  3. **协同审批批注留痕**：支持政审综合报告、廉洁意见书等多岗位在线留下修改意见与审查标记。

## 四、 可拔插抽象驱动设计 (Pluggable SPI Architecture)

为保障架构演进过程中**业务零侵入**，且支持在轻量级开发测试环境（无全套中间件）与企业级生产环境之间平滑切换，采用 **SPI 抽象驱动模式**：

### 1. 存储层抽象 (`StorageProvider`)
```java
public interface FileStorageService {
    String storeFile(MultipartFile file, Long memberId, Integer stepCode);
    Resource loadAsResource(String path);
    String generatePresignedUrl(String path, Duration expiry); // MinIO 直传/只读预览链接
    boolean deleteFile(String path);
}
```
- 实现类：
  - `LocalFileStorageServiceImpl`（`@ConditionalOnProperty(name="party.storage.type", havingValue="local")`）
  - `MinioFileStorageServiceImpl`（`@ConditionalOnProperty(name="party.storage.type", havingValue="minio")`）

### 2. 缓存层抽象 (`CacheProvider`)
- 保留系统基础内存缓存；
- 引入 `RedisTemplate` / `RedissonClient`，在配置 `spring.data.redis.host` 时自动装配分布式锁与分布式令牌中枢。

### 3. 搜索引擎抽象 (`SearchProvider`)
```java
public interface PartySearchService {
    void indexRecord(String index, String id, Object document);
    PageResult<SearchHitDTO> search(String keyword, SearchFilter filter, Pageable pageable);
}
```
- 默认提供基于 PostgreSQL 的基础检索降级实现；
- 在启用 ES 时无缝切换为 Elasticsearch REST Client，双写或基于 Change Data Capture 同步。

## 五、 企业级 Docker Compose 编排拓扑规划

后续在 `docker-compose.yml` 中扩充以下服务规格：

```yaml
version: '3.8'

services:
  # 1. 业务主库
  db:
    image: postgres:15-alpine
    container_name: party-postgres-db

  # 2. 分布式缓存
  redis:
    image: redis:7.2-alpine
    container_name: party-redis
    command: redis-server --requirepass ${REDIS_PASSWORD:-PartyRedis@2026}
    volumes:
      - redis_data:/data
    ports:
      - "6379:6379"

  # 3. 分布式对象存储
  minio:
    image: minio/minio:RELEASE.2024-05-10T01-41-38Z
    container_name: party-minio
    command: server /data --console-address ":9001"
    environment:
      MINIO_ROOT_USER: ${MINIO_ROOT_USER:-party_minio_admin}
      MINIO_ROOT_PASSWORD: ${MINIO_ROOT_PASSWORD:-PartyMinio@2026Secure}
    volumes:
      - minio_data:/data
    ports:
      - "9000:9000"
      - "9001:9001"

  # 4. 全文搜索引擎
  elasticsearch:
    image: elasticsearch:8.13.4
    container_name: party-elasticsearch
    environment:
      - discovery.type=single-node
      - xpack.security.enabled=false
      - "ES_JAVA_OPTS=-Xms512m -Xmx1024m"
    volumes:
      - es_data:/usr/share/elasticsearch/data
    ports:
      - "9200:9200"

  # 5. 在线文档服务
  onlyoffice:
    image: onlyoffice/documentserver:8.0
    container_name: party-onlyoffice
    environment:
      - JWT_ENABLED=true
      - JWT_SECRET=${ONLYOFFICE_JWT_SECRET:-PartyOnlyOffice@2026Secure}
    volumes:
      - onlyoffice_data:/var/www/onlyoffice/Data
    ports:
      - "8082:80"

  # 6. 后端与前端服务...
```
