# 红河数据产业集团有限公司党总支 · 智慧党建数字化管理系统

> **落实全面从严治党政治责任 · 全流程合规把关 · 一人一档全生命周期管理**  
> 严格遵循《中国共产党章程》、《中国共产党发展党员工作细则》（中办发〔2014〕33号）及《中国共产党国有企业基层组织工作条例（试行）》开发。

## 一、 系统简介与建设背景

**红河数据产业集团有限公司党总支 · 智慧党建数字化管理系统**是专为国有企业基层党建量身定制的数字化工作平台。系统紧扣国有企业“把方向、管大局、保落实”的政治定位，以全生命周期管理为核心，彻底解决基层党务工作中常见的“发展党员时序倒挂”、“带病入党风险”、“党员档案不全”、“三会一课台账零散”、“集中培训时长不达标”等迎检痛点。

## 三、 系统核心功能全景（7大业务模块 + 1个数字大屏）

### 1. 发展党员 25 步全流程管控（工作台）
- 覆盖《细则》5大阶段（申请入党 ➔ 积极分子培养 ➔ 发展对象考察 ➔ 预备党员接收 ➔ 转正归档）；
- **全流程据实同步闭环**：第 1 步申请人建档立卷即刻同步入库【党员花名册】（申请人状态）并自动开通账号；第 6 步、12 步、20 步、25 步关键节点据实逐级晋级花名册党籍状态与职务日期；
- **党务合规防错引擎（Hard Blocking）**：积极分子未满 365 天系统强制锁死、递交申请后 1 个月谈话倒计时、培训满 24 学时核验、纪委廉洁会签一票否决；
- **一人一档全景电子抽屉**：时钟轴进度、材料上传审核、审批记录与规范文书一键套打导出。

### 2. 党员花名册（党籍中台）
- **党龄根据入党时间自动核算**：自然周年计算规则，杜绝人工填报笔误与篡改；
- **人在A公司·党组织在B支部（跨单位解耦）**：支持组织关系所在支部与人事所属法人单位及部门自由解耦，自动打上【跨单位挂靠/派驻】特色标识，兼顾联合支部与外派骨干管理；
- **年度集中培训时长考核**：严格执行 **40 学时达标底线**，区分达标与待补训状态；
- **增删改查全支持**：支持在线新增、修改档案，支持下载标准 Excel 模板一键批量导入。

### 3. 党员转接及调整备案（独立专账）
- **组织关系转接台账**：详细记录转入、转出、介绍信凭证文号、原党组织、接收党组织、转接原因、党费交至年月与经办人；
  - **转入联动**：办理转入核准后，系统自动同步建档写入【党员花名册】并开通系统账号；
  - **转出联动**：办理转出后，系统自动将党员从【党员花名册】中除名注销，并归档转出存根；
  - **中组部标准凭证**：支持查看与打印《中国共产党党员组织关系转接存根凭证》；
- **党内职务调整备案**：详细记录干部任免、任职党支部、原职务、新任职务、调整类型、**批准文号/批复号**、生效日期、批准单位与职责分工；
  - **职务自动联动**：新增任免备案后，系统自动同步更新花名册对应党员的党内职务。

### 4. “三会一课”/组织生活台账
- **四类会议全覆盖**：支委会（月）、支部党员大会（季）、专题党课（季）、主题党日（月）；
- **动态研究议题与彩色标签**：会议决议上方可自由增加多条议题文本框，附带红金端庄彩色标签，管理员可在线新增自定义标签与颜色拾取；
- **五类证据链附件库**：会议通知、会议纪要原件、表决决议书、签到考勤表、现场照片；
- **复合筛选与在线修改**：支持党支部、会议类型、议题标签的单选/多选复合筛选，支持管理员在线修改完善会议记录。

### 5. 组织/个人奖惩或荣誉
- **双分类体系**：区分【组织奖惩/荣誉】与【个人奖惩/荣誉】，区分【荣誉表彰】与【纪律处分/诫勉】；
- **要素严密归档**：奖惩名称、级别（国家级/省部级/市州级/集团级/支部级）、文号、决定单位、生效日期、主要事迹与处分事实；
- **支持完整的增删改查**，处分记录与干部推优、发展政审一票否决联动。

### 6. 文书知识库（25步全景文档模板双轨制）
- 系统内置 25 份中组部标准空白 `.docx` 模板；
- 支持管理员在线导入企业红头定制模板；导出时优先使用定制版，支持随时一键恢复系统官方默认模板。

### 7. 通知中心（党建通知与多渠道触达）
- **5大渠道覆盖**：企业微信应用消息、钉钉工作通知、阿里云短信、系统站内信、邮件 SMTP；
- **生产级对接规范**：凭据由服务器环境变量注入（`PARTY_NOTICE_*`），数据库与后台仅存变量名，零明文泄露；
- **真实通信与回执**：外部渠道返回真实消息/任务回执编号（如 `msgid`、`task_id`、`BizId`），明确标注“服务商已受理，最终送达以服务商回执为准”；
- **合规扫描去重**：自动巡检支持 `dedupe_key` 唯一键防护，杜绝同日多次重复扣费或消息轰炸。

### 8. 智慧党建数字化调度指挥大屏
- **视觉风格**：坚决摒弃游戏化、科幻赛博风，严格对照党委机关与国企展厅严肃标准，采用故宫深红木底色与哑光党徽金；采用共产党员网官方标准金色党徽；
- **布局层次**：
  - 顶部：庄严对称抬头、实时时间、合规率 100%；
  - 上部：5 大 KPI 汇总卡（在册总数、正式党员、预备党员、发展对象、5委员/3支部）；
  - 中部：3 列黄金布局（左列队伍结构环形图与党龄柱图；中列 25 步阶梯流转看板与党总支 5 名委员联系督导矩阵；右列党纪监督雷达与双培养工程）；
  - **下半部通栏展开两大重磅压舱板块**：
    - 上栏：三家子公司党支部“三会一课”规范督查台账（红数信息、幂次科技、链达科技 3 列通栏拉长，展示主营业务与会议纪实）；
    - 下栏：紧扣主营业务设立的 4 大“党员先锋示范岗”实战阵地（4 列通栏拉长，展示一线攻坚成效）；
  - 最底部：通栏版本与庄严论述基座，稳如泰山。

## 四、 技术架构与轻量化工程设计

系统针对国企内部使用场景（低并发、高可靠、强合规）：
1. **数据库**：PostgreSQL 14+（采用专有 DDL，包含 13 张核心业务表与种子数据，支持转接与调整备案）；
2. **免 Redis 架构**：无状态 JWT Token 鉴权，字典数据与配置直接查库或利用 Spring 本地内存缓存（微秒级响应），无外部 Redis 依赖；
3. **免 MinIO 架构**：附件材料存储采用本地文件系统分级存储（`LocalFileStorageServiceImpl`），按 `uploads/模块/年/月/ID/` 分级规范存储，零外部对象存储依赖；
4. **多凭证统一鉴权体系（Multi-Credential Login）**：登录接口支持手机号码、员工工号、用户名三者通配鉴权，建档即开通账号，基层党员直接凭手机号与初始密码 123456 即可秒级登录；
5. **人事行政与党组织关系解耦体系**：支持“人在 A 公司，在 B 党支部”的国企外派/挂靠业务，自动打上跨单位派驻/挂靠标签；
6. **党籍全流程据实同步体系**：打破仅在转正才入库的断层，建档即入库（申请人），并在积极分子、发展对象、预备党员、正式党员等节点逐级据实升级。

### 核心技术栈

- **后端**：Java 21 LTS + Spring Boot 3.3.4 + MyBatis-Plus 3.5.7 + Apache POI 5.2.2 + poi-tl 1.12.2 + Spring Mail + Aliyun SMS SDK + Spring Security Crypto (BCrypt) + PostgreSQL Driver
- **前端**：Vue 3.5 + Vite 8.x + Element Plus 2.14 + ECharts 6.1

## 六、 生产级 Docker Compose 一键构建与部署 (推荐)

系统已完成全链路容器化配置，包含 **PostgreSQL 15 数据库自初始化、Spring Boot 3 (Java 21) 业务后端、Vue 3 + Nginx 前端** 三位一体编排。

### 1. 一键启动命令

#### Windows 环境：
直接双击根目录下的 **`docker-deploy.bat`**，或在命令行执行：
```bash
docker-compose up -d --build
```

#### Linux 服务器环境：
1. 复制并配置环境配置文件：
```bash
cp .env.example .env
vim .env # 填入真实的 PARTY_JWT_SECRET 及各通知渠道凭据
```
2. 赋予执行权限后一键运行：
```bash
chmod +x docker-deploy.sh
./docker-deploy.sh
```

### 2. 访问入口
- **业务管理平台与数字大屏**：`http://服务器IP` (或 `http://localhost:80`)
- **后端 RESTful API**：`http://服务器IP:8080/api`
- **PostgreSQL 数据库**：`服务器IP:5432`（默认库: `honghe_party_db`，密码: `Party@Honghe2025`，容器启动时自动执行 `docs/schema-pg.sql` 完成 11 张表及全部种子数据初始化）

### 3. 常用容器运维命令
```bash
# 查看容器运行状态
docker-compose ps

# 查看实时服务日志
docker-compose logs -f

# 停止并清理容器
docker-compose down

# 重启所有服务
docker-compose restart
```

## 七、 本地开发与免容器调试指引

若在无 Docker 的开发机上调试：

### 1. 运行前端看板
直接双击根目录下的 **`start-demo.bat`**，或执行：
```bash
npm run dev
```
浏览器访问：`http://localhost:5173`。

### 2. 运行后端服务
在 `backend` 目录下执行：
```bash
cd backend
mvn spring-boot:run
```
后端服务运行在 `http://localhost:8080/api`。
